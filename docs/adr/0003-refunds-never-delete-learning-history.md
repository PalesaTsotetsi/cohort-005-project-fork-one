# Refunds never delete a learner's learning history

Approving a Refund Request removes access but never deletes the learner's lesson progress or video watch history. We chose this over deleting or resetting it so that a learner who buys the course again picks up where they left off, and so that how much they watched before the Refund stays on record if the Refund is ever disputed. Each decided Refund Request also stores a snapshot of the figures the Admin saw (amount paid, days since purchase, Course Progress, Watch Time), because those can't be reconstructed later once the learner keeps watching or buys again.

## Consequences

- Any future "delete my data" or retention requirement must deliberately handle refunded learners' history; it will not disappear on its own.
